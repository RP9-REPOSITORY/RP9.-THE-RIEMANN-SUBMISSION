README — D. RP9. SUBMISSION. FINAL REVIEW

DOCUMENT OVERVIEW

This README identifies the three review templates, the material to supply, their execution conditions and report identities.

Each template defines its own operations, evidence requirements and output.

MATERIAL ACCESS AND SHARING

The material may be supplied as the Submission's three source branches, A–C, together with their respective M.R.F. files and indexes. Branch D provides the review templates and execution instructions.

Each M.R.F. file consolidates the source material from the folder identified by its name. Its source metadata identifies the included files and their locations. The corresponding index provides navigation to the individual source files.

These consolidated files provide an additional means of sharing material for review. The original folder structure remains the reference for source identity and relationships.

Recommended preparation and sharing sequence:

  1. Download and extract the Submission package.
  2. Apply PRE-Auto_FIX.bat where filename correction is required, following its README.
  3. Extract the required A.P.X. archives and any separately packaged source or output material.
  4. Supply the current branch READMEs, the corresponding M.R.F. files and indexes, and the review template to be executed.
  5. Include separately any required source or output files not contained in the supplied M.R.F. files.

This sequence is recommended to preserve structural integrity, source traceability and the functional relationships between the supplied materials.

The person supplying the material chooses the delivery method and is responsible for ensuring that the selected files are complete, mutually consistent and accessible to the reviewer.

A provides the presentation and derivation. B provides executable source and recorded computational evidence. C provides supplementary explanations.

The M.R.F. files represent their included sources. Support explanations and reviewer guides do not replace derivation, executable source or recorded output.

3. EXECUTION

Supply each template separately with the instruction:

Execute the attached review according to its instructions.

The standard execution order is:

  1. RP9. A. FINAL SOURCE-BOUND.md
  2. RP9. B. REVIEW INSTRUCTION AND EXECUTION.md
  3. RP9. C. POSITIONS AND CLARIFICATIONS.md
  4. RP9. D. META-REVIEW OF REVIEW ARCHITECTURE AND EXECUTION

A and B are independent. Neither requires the other's execution, approval or result.

C requires the B instruction and completed B report from the same review run. A completed B report contains six supported responses, completed aggregation and a final determination.

Either COMPLETE FUNCTION LOCK or FUNCTION BREAK permits C to be applied. C does not alter that determination.

If B is incomplete or its completed report is unavailable, follow C's non-execution instruction.

D Examines whether the audit architecture and its implementation maintain the same operational system-logic focus as that applied to the material presented.
